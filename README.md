# Vaylento Website

Static, responsive one-page website for Vaylento — Outsourced Travel Operations.

## Files
- `index.html` — complete website (HTML + CSS)
- `assets/logo.svg` — Vaylento logo
- `assets/hero.png` — hero/feature travel image

## Before publishing
1. Replace `YOUR_EMAIL_HERE` in `index.html` with the business email you want to receive inquiries on.
2. Replace the two example testimonial labels with real client proof only after you have permission and actual clients.
3. Add real LinkedIn/WhatsApp links when ready.

## GitHub Pages
Upload the folder contents to a GitHub repository and enable GitHub Pages from the repository's Pages settings, using the `main` branch and `/ (root)`.
